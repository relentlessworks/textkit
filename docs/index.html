textkit

Agentic-first text analysis and manipulation service. Plain text API, agent-driven, single Go binary.

Go Plain Text API MCP Self-Documenting Single Binary No Database
View on GitHub Quick Start

Principles

Agent IS the Interface

No UI, no SDK. The API is the product.

Plain Text by Default

One labeled, grepable line per record. JSON on demand.

Instructive Errors

Every 4xx includes a hint for self-correction.

Self-Documenting

GET /help returns the full operating manual.

Single Binary

Go, CGO_ENABLED=0, zero external deps.

MCP Connector

Speaks Model Context Protocol at /mcp.

Quick Start

make build
./textkit

curl -X POST localhost:8080/stats -d "Hello world. This is a test."
curl -X POST "localhost:8080/wrap?width=20" -d "The quick brown fox"
curl -X POST "localhost:8080/sort?desc=true" -d "banana
apple
cherry"
